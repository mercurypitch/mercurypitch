# A painting per station

Drop a station's painting here as `<faculty>.webp`: `resolution`, `function`,
`shape`, `colour`, `time` or `wild`. Every drill at that station then sits in
it, with no code change (`stationPainting`, `../stations.ts`); the build picks
the file up and ships it with the Ear Lab with Merc's chunk, so the store
build carries none of it until the switch is on there.

Until a station has one, its drills sit in the Regulator Room, and Wild's in
the glasshouse.

What the room expects of one, so the instrument lands in its light:

- Portrait, 9:16, 1440 x 2560 like `public/ear-lab/regulator-room-portrait.webp`.
- The pool of lamp light on the desk at 57% of the height, centred, where the
  room puts the instrument and its contact shadow.
- A dark top fifth for the header and a dark bottom third for Merc's console;
  the room shades both, but a bright sky there fights the text.
- WebP, under about 400 KB.
