Arpeggio Jumper's grade blended the note average with the best note (30 %) and a "richness" reading on the wrong scale (25 %), so a flawless run could not pass 75 and the drill's level could never rise above 5. This is its scoring version 2: the grade is the average of the note scores, each note is scored on what was sung in its own turn, and a whole run sung an octave up or down is scored there. On 25 October the owner said yes to the average, to forgiving a whole-run octave, and to at least 1.2 s for each note.

It also takes the same dead richness term out of four other drills' grades, and makes the level, the weak-drill list and the per-drill trends read only runs on a drill's current scoring.

## The rule

- **What a note scores.** `round(max(0, 100 − 1.5 × mean |cents|))` over the settled frames of the note's own window: the first 15 % is left out. A note with nothing voiced scores 0 and is reported as not sung.
- **The grade.** The mean of the note scores. The best note stays on the result line as praise. The live readout ends on the same number as the grade.
- **Note by note.** The window opens the tone's length plus 250 ms after the tone is scheduled. It never opens when `playTone` resolves, because that happens at scheduling: the reference tone was being scored. The window lasts `max(1200, round(2000 × f))` ms.
- **Echo the phrase.** Each demo tone plays in full. Slot 0 starts `round(700 × f)` ms after the last tone ends, and each slot lasts `max(1200, round(1300 × f))` ms.
- **Latency.** Every window and slot is read one measured mic round trip later. An unmeasured round trip reads as 0.
- **Octave.** The run is scored in one octave, the guide's or one above or below, whichever gives the least total error. Each note keeps its own target in that octave, so the leap to the top do must still be sung.
- **No result.** A run with nothing voiced, or stopped before its end, is not recorded, does not move the level and shows no grade (REQ-GVC-031). The idle panel says which: "We didn't hear any singing, so this run was not scored. Check the microphone, then try again." or "You stopped before the end, so this run was not scored."
- **Result line.** "Best note: N% · Landed: H of T", then " · Not sung: U" when U > 0, then "Scored an octave above the guide tone." (or below) when the run's octave is not the guide's.
