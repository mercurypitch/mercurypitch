# Rose crystal hex crumble v3

This package finishes the accepted Rose Hex donor as an optional crackle deck
for the Cloudway mechanics preview. The dense donors, v1 and v2 comparisons,
packed Blender masters, textures, production recipe, and complete proof set stay
in the Proton-linked creative archive. The game ships reviewed desktop and
balanced-mobile v3 derivatives only.

The runtime root is `Cloudway_RoseCrystalHexCrumble_V3`. Its intact state uses a
preserved etched detail surface, one closed outward-wound glass volume, and the
original gold hardware. Its fractured state uses 24 closed glass shards while
the hardware remains. The renderer draws three material primitives while intact
and 25 while fractured; the 28 primitives stored in the GLB are mutually
exclusive authored states rather than simultaneous draw calls.

Gameplay support is the exact six-point convex polygon in
`production-receipt.json`. The rectangular AABB corners are intentionally empty.
Core collision validates the polygon, uses circle-versus-polygon top support,
and sweeps the polygon sides at both normal and high frame deltas. The preview
keeps the established `preview-rose-step` platform identity and progress data.

The desktop tier is 84,213 triangles with three referenced images and about
48 MiB of decoded mip storage. The mobile tier is 53,358 triangles with the same
roles and about 12 MiB of decoded mip storage. Every fracture clone owns its
geometry and the focused lifecycle proof disposes each clone exactly once.
