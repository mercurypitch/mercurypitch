# Pearl teal quarter-turn A

This package turns the reviewed Meshy quarter-turn donor into a reusable static
Cloudway path module. The dense donor, packed Blender master, editable textures,
decoded audits, and full production proof remain in the Proton-linked creative
archive. The game ships separate desktop and balanced-mobile derivatives.

The runtime root is `Cloudway_PearlTealQuarterTurnA_V1`. It carries three opaque
PBR material roles: pale marble, gold hardware, and teal inlay. The high tier is
68,000 triangles with 2048-pixel base colour and normal textures; the mobile tier
is 31,996 triangles with 1024-pixel base colour and normal textures. Both use
three mesh draws per render pass.

Gameplay support is an exact two-box union under one public platform identity.
The source's 0.52-metre arms are baked at 1.6 horizontal scale, making a
0.832-metre lane with 0.512 metres of width beyond Merc's collision diameter.
Named support and dock nodes use metres and glTF +Y-up coordinates. The concave
inner quadrant stays unsupported. The renderer accepts always-active static deck
parts only; it rejects independent activation or movement.

The selectable preview is **The Pearl Turn** in the owner build. In a development
browser, open `/glass-game/?layout=quarter-turn-art`. Actual WebGL proof verified
that the high profile loads the desktop GLB and compact balanced devices load the
mobile GLB. Merc crossed both docking seams and the elbow without leaving the
authored top plane. The repaired source corner and reduced mobile scallops were
also inspected under the Cloudway's grazing light.

See `recipe.json` for the production decisions, `production-receipt.json` for
the exact runtime contract, and `proof-manifest.json` for portable hashes of the
private masters and accepted proof captures.
