# Frost gold arch breakwall A v1

This package finishes the accepted Frost Gold Arch donor as a breakable barrier
in the optional Cloudway mechanics preview. The dense donor, packed Blender
masters, source textures, production recipe, and complete Blender proof remain
in the Proton-linked creative archive. Separate desktop and balanced-mobile GLBs
ship only when this optional preview route is selected.

The runtime root is `Cloudway_FrostGoldArchBreakwallA_V1`. The permanent ornate
frame is `frost_arch_frame`; `frost_arch_intact` and 32 named closed shards form
the removable frosted pane. Frame art and pane art retain separate material
roles, and fracture preparation reuses the existing bounded vessel lifecycle.

The pane collision is not its rectangular visual bounds. One lower box plus 15
measured narrowing crown bands fill the arched pane while leaving less than five
millimetres at the apex. Two grounded post boxes remain after shatter. The crown
begins above the adjacent support's measured maximum jump plus Merc's collider
height, so reachable movement cannot enter an unmodelled frame underside. The
decorative inner trim reaches 11.3 millimetres below the structural floor datum;
it does not extend collision.

The desktop tier is 106,801 triangles, 68 stored primitives, and about 57.5 MiB
of decoded texture mips. The mobile tier is 53,641 triangles with the same 32
shards and about 14.4 MiB of decoded texture mips. Stored shard primitives are
inactive until fracture and should not be counted as simultaneous renderer calls.
