# Living Glass through The Thawing Song

This pass extends the accepted Living Glass trial into an existing complete
course. It keeps the Thawing Song's five-note lesson, two gates and portrait
finale. The source revision, encounter IDs, checkpoints, jump gaps, collision
surfaces and saved melody identity remain unchanged.

## Placement

| Singing stop      | Existing support slabs | Treatment                                                  |
| ----------------- | ---------------------- | ---------------------------------------------------------- |
| A tiny spark      | `thaw-arrival-2/3/4`   | Warm pearl current, Rosebud and a gentle resonance release |
| A little brighter | `thaw-lantern-1/2/3`   | Mint and lilac current, brighter resonance                 |
| Home again        | `thaw-home-1/2/3`      | Moonlit pearl current and a softer return                  |

Each group replaces the appearance of contiguous static slabs. Their complete
walkable rectangle remains visible: the certified glass donor keeps its original
dimensions, with a narrow marble and gold surround covering the remaining
support. No invisible extension, stretched donor or duplicated floor is needed.

Presentation definitions carry the group, room, response encounter and effect
parameters. Validation rejects disconnected, overlapping, non-coplanar or
unknown groups. Palette and timing changes do not require another model export.

## Ownership and cost

Three Rosebuds share one prepared intact geometry and fracture set per bundle
installation. Materials, transforms, charge, cracks and release states belong to
each exhibit. Geometry survives until its final owner releases it. Cancellation,
late cosmetic downloads, failed installation and renderer teardown retain that
ownership contract.

Explicit exhibit-to-room assignments extend the existing room visibility system
to the course's plain encounter IDs. Hidden presentation work may be skipped;
authoritative break state must still be ingested. Reflection captures temporarily
restore the visibility they require and restore normal visibility afterward.
Walkable supports are never hidden merely to meet an arbitrary object-count cap.

This pass adds no runtime model or texture bytes. The existing Rosebud and Living
Crystal files are reused. New glassware production has a separate measured
delivery budget; the native package cap stays unchanged.

## Verification

Focused tests cover the physical-course invariants, support coverage, explicit
room ownership, material isolation and final-owner disposal. Browser tests load
the real assets once, cancel and repeat each of the three sung targets through
real oscillator PCM, then reload the saved result and melody key. These input
tests suppress expensive draw calls and do not establish rendering performance.

Separate actual-render captures inspect all three stops, their contact edges,
phone-width layouts and singing camera. Production masters and full-resolution
proofs remain in the synced creative archive, alongside the private execution
checklist. Physical-phone performance remains a device-test gate.
