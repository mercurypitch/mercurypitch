# Studio kit provenance

The Studio one-shots are curated derivatives of Virtuosity Drums.

- Project: Virtuosity Drums by Versilian Studios
- Performer: Austin McMahon
- Source: <https://github.com/studiorack/virtuosity-drums>
- Pinned source commit: `d41b734e9ce5edce1be375c262b2644de4387061`
- License: CC0 1.0 Universal
- License URL: <https://creativecommons.org/publicdomain/zero/1.0/>
- Changes: a compact set of close/mid microphone recordings was selected,
  resampled to 44.1 kHz stereo, and encoded as 112 kbit/s MP3 one-shots. No
  dynamic normalization or tail trimming was applied.

The original project dedicates the recordings to the public domain under CC0.
The catalog beside these assets records the exact source path and SHA-256 for
every derived file.
