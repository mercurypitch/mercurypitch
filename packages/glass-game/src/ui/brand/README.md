# Glassworks museum lettering

`glassworks-wordmark.svg` contains only the outlined word Glassworks, using
Cormorant Garamond at weight 400. The glyph spacing, placement, and gold surface
were adapted for this lockup. No font file is shipped or fetched at runtime.

Font source: [Google Fonts Cormorant Garamond](https://github.com/google/fonts/tree/main/ofl/cormorantgaramond).
Retrieved 11 October 2026. Copyright 2015 the Cormorant Project Authors.
License: SIL Open Font License 1.1; preserved in `CormorantGaramond-OFL.txt`.
Source variable font SHA-256:
`b20b7d9626dd956b2c5e558692ad328b1f19e3275e2782db4fa07670d83f35e0`.

The sun crest and divider in `MuseumBrand.tsx` are custom vectors drawn for this
museum, based on the approved composition. The wordmark remains a real heading
with its accessible name. The original tagline remains live text.
