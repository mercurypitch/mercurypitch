## Remaining high: unpublished braces patch

[GHSA-vfj7-8cjw-p6xm](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm) reports stack exhaustion on deeply nested patterns in `braces <=3.0.3`; the GitHub advisory lists no patched release. The npm audit metadata names `>=3.0.4` as patched. On 2026-10-13 the [npm registry](https://registry.npmjs.org/braces) contains no `3.0.4`; its latest published version remains `3.0.3`. We retain the advisory rather than suppress it or point the lockfile at an unavailable release.

Observed paths are `jscpd → @jscpd/finder → fast-glob → micromatch → braces` and `@gltf-transform/cli → micromatch → braces`. These are development tools. No app/worker import of braces was found. The practical exposure is attacker-controlled glob patterns passed to those tools; repository-controlled scan patterns do not establish a remote app exploit. Do not feed untrusted patterns into these commands. Update to a published fixed release, or a parent version that removes this path, when available.

## Critical risk and release implications

- [Capacitor GHSA-rvm3-566m-v7fv](https://github.com/ionic-team/capacitor/security/advisories/GHSA-rvm3-566m-v7fv) affects the internal HTTP interceptor route in the native WebView. Merely leaving CapacitorHttp disabled is not a mitigation for affected versions. The source upgrade and regenerated native references must reach rebuilt, redistributed apps; already installed binaries remain unchanged by this PR.
- [Seroval GHSA-p6vx-979v-rg4c](https://github.com/lxsmnsyc/seroval/security/advisories/GHSA-p6vx-979v-rg4c) concerns untrusted serialized input and plugin-produced thenables. Updating Solid to its patched 1.9 release line selects Seroval 1.6.9 without overriding Solid’s declared dependency contract.
- [shell-quote GHSA-w7jw-789q-3m8p](https://github.com/ljharb/shell-quote/security/advisories/GHSA-w7jw-789q-3m8p) concerns attacker-controlled operator objects passed through quoting to a shell. The installed path is npm-run-all; the update also covers its later high-severity advisory.

## Compatibility and validation

Capacitor core, CLI, Android and iOS move together to 8.5.3. Solid, Vite and Sharp minimum ranges are raised across affected workspaces. Official compatible parent updates to Transformers 4.3.1, glTF Transform 4.5.1 and Wrangler 4.150.0 remove old Sharp, adm-zip and Undici resolutions. Wrangler’s Workers types peer is updated with it. The existing build-script allowlist and tinyest compatibility override are unchanged.

The only new overrides are security patches for compression (serve pins the vulnerable patch exactly) and Immutable 5 (within Sass’s accepted range). Browser speech workers use Transformers. Focused speech service, hook and pitch-asset tests passed (41 tests across 6 files; the Worker boundary is mocked). A headless Chromium smoke loaded the actual q8 Whisper model and the new ONNX WASM runtime, ran inference on synthetic silence with word timestamps, and disposed the pipeline. This verifies WASM compatibility, not WebGPU or transcription accuracy. Sharp PNG encoding and glTF Transform CLI startup also passed. Native web bundles and Capacitor references are checked locally; native device release testing and redistribution remain a release activity.

The root, DB Worker, Jam Worker and both mobile app typechecks pass. Both mobile web builds and all four Capacitor platform updates pass. The full browser build passes its existing bundle audits after separating Solid's optional store runtime from the shared core chunk; Drum Night starts at 516,197 bytes against its unchanged 520,000-byte limit. Hosted CI provides the full repository test and native build gates.
