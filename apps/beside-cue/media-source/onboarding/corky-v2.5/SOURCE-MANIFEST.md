## Reproduction

Run from the repository root:

```sh
rtk node scripts/prepare-beside-cue-v2-5-media.mjs \
  --b01-source '<user-dotfiles>/besidecue/assets/onboarding-video-edit-v2_5/assets/picture/b01-corky-greeting-direct-to-p02-v0_1.mp4' \
  --h06-source '<user-dotfiles>/besidecue/assets/generated_video_outs/gemini/h06-google-flow-omni-flash-v0_1-silent.mp4' \
  --spin-source '<user-dotfiles>/besidecue/assets/generated_video_outs/gemini/b06-whole-vinyl-rigid-spin-google-flow-omni-1_1-flash-frames-raw-v0_1.mp4'
```

The command builds in a private temporary directory, validates all frozen
input hashes and streams, then replaces only the three named product movies,
the public hash inventory, and the generated build contract.
