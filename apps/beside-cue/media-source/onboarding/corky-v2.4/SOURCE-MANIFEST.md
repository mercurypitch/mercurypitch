# Beside Cue V2.4 app-preview source manifest

This is the reproducible source record for the integrated V2 onboarding media
in MercuryPitch draft PR #689. The founder explicitly approved the frozen
V2.4 picture and the selected separated V0.1 audio for Android draft testing
on 2026-09-01. The media is approved for this draft Android test; normal
application release review still applies.

The delivery pack is generated by
`scripts/prepare-beside-cue-v2-4-media.mjs` (SHA-256
`4a0e244729e5f4d41419d670884fa7d30275a8944f9afadea500e59487c222c8`)
with Node v25.8.2 and FFmpeg n9.0.1. The script refuses every unpinned source,
strips provider audio from picture, and installs outputs atomically.

## Reproduction

Run from the repository root:

```sh
rtk node scripts/prepare-beside-cue-v2-4-media.mjs \
  --source-package '<dotfiles>/personal/besidecue/assets/onboarding-video-edit-v2_4' \
  --legacy-audio-package '<dotfiles>/personal/besidecue/assets/onboarding-video-edit-v0_1'
```

The command rebuilds into a private temporary directory, validates codec,
geometry, frame-count, audio-stream, and source-hash contracts, then replaces
only the named delivery files and both generated hash records.
