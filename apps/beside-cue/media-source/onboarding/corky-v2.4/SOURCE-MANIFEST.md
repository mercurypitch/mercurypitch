# Beside Cue V2.4 app-preview source manifest

This is the reproducible source record for the integrated V2 onboarding media
in MercuryPitch draft PR #689. The founder explicitly selected the generated
Corky entrance, the frozen V2.4 set, and the separated V0.1 audio for Android
draft testing on 2026-09-01. The media is approved for this draft Android
test; normal application release review still applies.

The delivery pack is generated by
`scripts/prepare-beside-cue-v2-4-media.mjs` (SHA-256
`2387e3764c52934401127089afaeb9837c1357a4b88f15ec851ee23744cebdc4`)
with Node v25.8.2 and FFmpeg n9.0.1. A separate run with the repository's Node
v22.22.2 rebuilt the public closed set and build contract byte-for-byte. The
script refuses every unpinned source, strips provider audio from picture, and
installs outputs atomically.

B01 is a deterministic 151-frame edit at 24 fps. Delivery frames 0–88 are raw
frames 0–88. Delivery frames 89–124 expand raw frames 89–109 from 21 to 36
frames by explicit nearest-frame duplication; there is no interpolation.
Frames 125–132 slide the lossless B02 frame-19 paper texture left-to-right over
held raw frame 109 in eight 90-pixel steps. Frames 133–134 are fully opaque
paper over the raw base; frames 135–136 are the same fully opaque paper over
exact P01, hiding the base switch between frames 134 and 135. Frames 137–144
continue the wipe left-to-right to reveal exact P01 in eight 90-pixel steps,
and frames 145–150 are exact P01. The generated AAC track is discarded.

B02 delivers all 48 source frames unchanged. Each Pull is composed at
1080×1920 as P02 + authored shadow + authored foreground, then
Lanczos-downsampled once. Its P03 still is exact delivered Present frame 95.
Sugarlump therefore uses one continuous-performance identity on both sides of
the shared hold; no legacy M03 pose or bridge pixels are inserted.

## Reproduction

Run from the repository root:

```sh
rtk node scripts/prepare-beside-cue-v2-4-media.mjs \
  --source-package '<user-dotfiles>/besidecue/assets/onboarding-video-edit-v2_4' \
  --legacy-audio-package '<user-dotfiles>/besidecue/assets/onboarding-video-edit-v0_1' \
  --corky-entrance-raw '<user-dotfiles>/besidecue/assets/main_higgsfield_ref/gemini/Corky_entering_and_greeting_viewer_202609011829_no_long_legs.mp4'
```

The command rebuilds into a private temporary directory, validates codec,
geometry, frame-count, audio-stream, and source-hash contracts, then replaces
only the named delivery files and both generated hash records.
