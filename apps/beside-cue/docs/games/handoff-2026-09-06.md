## 4. Conventions maff enforces (all of them have bitten)

- No emojis anywhere. No `Co-Authored-By` or any attribution in
  commits or PR bodies. Never mention timelines or durations.
- One PR per step; rebase-merge; squash fix-ups first; never a merge
  commit in a branch (`git rebase origin/main` to sync). Before any
  force-push, `git log --oneline origin/main..HEAD` must show what you
  expect -- a rewrite that failed silently once pushed an empty branch
  and GitHub auto-closed the PR. `git cherry-pick` has no `-q`.
- Never kill a process by name or pattern; only your own port or PID.
- Output files (screenshots, reports, PR bodies) go to
  `~/agent-out/mercurypitch-shipaton/<YYYY-MM-DD>/`, never the
  scratchpad. Wrap long commands in `timeout`.
- Image generation: `ask-codex` and `ask-antigravity` skills, not
  Higgsfield. Meshy calls cost credits and need a confirmation.
- Fixtures never carry real personal data.
- Doc style: prose, the reasoning beside the number, decisions
  recorded where they land; comments in code say WHY and who found it.
- Prettier rewraps long lines; a python patch that anchors on your own
  unformatted text will miss -- anchor on formatted text or regex.
  Heredocs with `'TS'` keep backslashes literal; import lists are
  multi-line in the file though the shell hook collapses them.

## 6. Known findings worth not rediscovering

- Merc's root origin is his vertical CENTRE (§14.3 of the Line plan);
  the anchor holds the torso bottom still. The Line stands his torso on
  the floor (`feetBelowRoot`); the chambers and Hallway still put the
  root at floor level against a gradient floor.
- `SkinnedMesh` cancels node transforms via `bindMatrixInverse`; the
  face cannot be counter-scaled. `Box3.setFromObject` caches the bind
  pose; use `computeBoundingBox()` for posed boxes.
- `bandFor`: `tLimit` is the band's EDGE on both ends; `semis` the
  least width. A wedge's band closes with position (`bandAt`); a wall
  is never behind him (`wallAt`).
- Under `w²h = V` the body has one degree of freedom: every static
  gate is a `t`-interval. The shape buys opposition along the walk and
  a profile in `x`. (Line §16.2.)
- The grade's stop is a stillness WINDOW (0.1 semitones for 150 ms),
  never a velocity: tracker jitter is a semitone a second at 60 Hz.
- The pane's three-quarter chase camera lags after a `warpTo`; wait a
  few frames before judging framing.
- The PMREM is sized from its source; author the env map at 1024×512.
  The rig is world directions (`RIG`) shared by map and lights.
