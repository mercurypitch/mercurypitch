# Lead notes (backup)

Working notes for the Find Your Pitch lesson builds, backed up from the
session's scratchpad. This branch is never merged.

- `NEXT.md`: the queue, the owner's decisions, open PRs, what runs now.
- `PAUSED.md`: where each paused piece of work stopped, and what it needs next.
- `l9/`, `l10/`, `l11/`, `l12/`: build plans, decisions and follow-ups.
- `arp/`: the arpeggio grading consensus.
- `tour/`: the lesson page tour plan.
- `bin/`: the lane scripts builders run tests through, and the fold helper.

Builder ids are replaced with "(builder)". The work itself is on the `feat/`
branches these notes name.

Restore into a scratchpad:
`git fetch origin feat/lead-notes && git archive FETCH_HEAD | tar -x -C <scratchpad>`
